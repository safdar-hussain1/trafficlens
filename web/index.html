        How it works

        Three steps run on every frame, inside this tab.

        1. 1Detect

          A YOLO11n detector finds the vehicles in each frame and labels each one car, truck, bus or motorcycle. It runs on your graphics card through WebGPU, or on the processor through WebAssembly.

        2. 2Track

          A Kalman filter predicts where each vehicle moves next, and the Hungarian algorithm matches those predictions to the new detections, so every vehicle keeps one ID from frame to frame.

        3. 3Count

          When a tracked vehicle's path crosses your line, it is counted once, by type and by the direction it went. Move the line and counting starts again from there.

        The model downloads once and stays in your browser's cache. Every frame is read, detected and discarded inside the tab, and nothing is uploaded.

        Checked against crossings counted by hand

        Every vehicle crossing the line in the motorway clip was labelled frame by frame. The engine's counts were then scored against those labels, one crossing at a time.

        The same engine in Python and in your browser

        The counting engine is written twice: in Python, where it is benchmarked, and in TypeScript, which runs on this page. Recorded Python runs are replayed in your browser and must produce the same tracks and the same crossings.
